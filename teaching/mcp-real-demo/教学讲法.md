# 真 MCP 课堂讲法

## 开场一句话

这个版本和前面的模拟版最大区别是:

`它已经可以当成真正的 MCP server 被宿主拉起来。`

## 你可以这样讲

### 第一步

先告诉学员:

- 宿主负责启动 MCP server
- server 通过标准输入输出收发消息
- 消息不是随便一行 JSON
- 而是 `Content-Length` 包头加 JSON 正文

### 第二步

现场执行:

```powershell
cd D:\opencalw\teaching\mcp-real-demo
python .\probe_client.py
```

告诉大家:

- 这里的客户端已经不是之前那种“换行分隔 JSON”
- 而是标准 MCP 报文

### 第三步

打开 [mcp_server.py](D:\opencalw\teaching\mcp-real-demo\mcp_server.py)，重点讲 3 个函数:

- `read_packet`
- `send_packet`
- `dispatch`

### 第四步

再解释业务能力:

- `tools` 是动作
- `resources` 是资料
- `prompts` 是模板
